YOUR GAME BOY, YOUR CONTROL

Pair your GameHub Mini.

Connect your ESP32-WROOM-32 to the internet, then enter the six-digit PIN shown on its display. Or use the USB cable connection below. Both methods are available on this page.

01 / CHOOSE YOUR DISPLAY

Which Game Boy are you using?

1.3-inch OLED selected. Downloaded games use its monochrome layout.

PIN pairing requires the matching Netlify Function and Netlify Blobs store. A static-only Netlify Drop can show this page but cannot complete pairing.

02 / CONNECT DEVICE

Enter pairing PIN

Your ESP32 and phone/laptop need internet to reach the Netlify bridge. If PIN pairing is unavailable, use the direct USB option below.

ALTERNATIVE / USB CABLE

Connect directly over USB

This method does not need a PIN, Wi-Fi or the cloud bridge. Use a USB data cable and desktop Chrome or Edge. Upload the USB-compatible GameHub main.py first, then close ESP IDE and ViperIDE serial monitors before connecting.

USB not connectedWaiting for a USB serial connection

Click Connect and select your ESP32 serial port. HTTPS and Web Serial support are required.

USB CONTROLLER

USB button presses are sent directly through the cable. Physical buttons still work. USB commands temporarily take priority over cloud commands while the USB page is active.

03 / REMOTE CONTROL

ESP32 Controller

Checking…SH1106 • 128×64 OLED

Commands are best-effort and may take a few seconds. Fast action games play best using physical buttons on the console. The game downloads below save files to your browser; direct microSD installation is not enabled yet.

04 / GAME LIBRARY

Download more games

Optional MicroPython game modules for future firmware expansion. The current all-in-one Snake/Pong firmware cannot load these modules until the game loader is added.
