How real storage reporting will work

After we build the ESP32 firmware, the console can report actual mounted filesystem sizes.

🧠

ESP32 onboard flash

The ESP32 can calculate available filesystem bytes using MicroPython os.statvfs('/'). This is not necessarily the full flash chip.

💾

TF / microSD card

When the card reader works and the card is mounted, os.statvfs('/sd') can report actual capacity and free space.

🛡️

Safe formatting

Future firmware must authenticate requests, identify the exact TF card, require explicit confirmation, and never allow formatting internal ESP32 flash by accident. Formatting will not be simulated as a real operation.

🔌 Tiny OLED wiring — ESP32 DevKit

For an SSD1306-compatible 128×64 I²C OLED. Check the module's markings and use 3.3V logic.

OLED

SDA → GPIO21
SCL → GPIO22
VCC → 3V3
GND → GND

Directions

UP → GPIO32
DOWN → GPIO33
LEFT → GPIO25
RIGHT → GPIO26

Game buttons

A → GPIO27
B → GPIO14
START → GPIO18
SELECT → GPIO19

Each button closes between its GPIO and GND; code enables internal pull-ups. Optional active buzzer: leave disabled until the buzzer wiring is verified. A four-pin OLED has no microSD slot: use compatible external microSD hardware if needed later. Power the ESP32 via USB for initial testing.
