HOW IT WORKS

Your files, your library

Files are saved in this browser using IndexedDB. They are not automatically uploaded to the ESP32.

  • .html — open in a new browser tab
  • .js — keep as a source file
  • .py — download and transfer to ESP32 with your IDE
  • .zip — save your project archive

Where is my storage?

GameHub saves your game list, screen-time total and settings in this browser. Uploaded files are stored in IndexedDB on this device. Clearing browser website data may remove these local files. This is not ESP32 flash or microSD storage.

Not connected yetChoose a connection method below.

Connect your ESP32 to Wi-Fi. Open WEB / PAIR on its screen. Use the same six-digit PIN shown there. The ESP32 keeps one PIN for its active pairing session; it must show “Bridge connected” before you submit it.

Waiting for a PIN pairing session.

Use a USB data cable and a compatible browser. Android USB is optional and not recommended; Wi-Fi PIN pairing is easier. Close ESP IDE / ViperIDE serial monitors before connecting.

USB connection not started.

USB direct control requires a data cable and browser Serial API support over HTTPS. Android/iPhone USB support varies; use Wi-Fi PIN pairing on phones. Browser support details.
